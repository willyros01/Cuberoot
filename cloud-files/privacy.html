Privacy Policy

Cloud Files is a browser-based portal for Apple's iCloud Drive and local files on the Fire device.

Cloud Files does not keep a Recent Files history. A locally selected file is used only to show its basic details in the current session and is not uploaded by Cloud Files.

If location permission is allowed, coordinates are used locally only to calculate sunrise and sunset for automatic day/night appearance. Cloud Files does not transmit or store the location.

iCloud sign-in, browsing, uploads, downloads and storage are handled by Apple. Local download destination is controlled by the Fire browser/device.
