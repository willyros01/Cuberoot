Upload to iCloud

⬆️

Upload a Fire File

Uploads are started inside Apple's iCloud Drive.

Upload

  1. Tap Open iCloud Drive below.
  2. Open the iCloud folder where you want the file saved.
  3. Tap Apple's Upload control.
  4. Choose Choose Files.
  5. Select the file from your Fire.

iCloud opens in a separate Silk tab so Cloud Files stays open. Switch back to the Cloud Files tab when finished.

Cloud Files v1.7.3

Download from iCloud

⬇️

Download a file to this device

  1. Tap Open iCloud Drive below.
  2. Find the file you want to download.
  3. Select the file, then use Apple’s Download control.
  4. After the download, find the file in your browser’s Downloads area or the device Downloads / Files area.

Cloud Files does not control the screen shown after Apple completes the download.

Local Files

Local Files uses the Fire's native file picker. Use Browse Local Files to locate or confirm a downloaded file, normally in Downloads.
