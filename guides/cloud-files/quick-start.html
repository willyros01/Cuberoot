Cloud Files

Quick Start Guide — Amazon Fire HD 8

Based on Cloud Files 1.7.3 · October 12, 2026 · Android test edition

Use Cloud Files to reach Apple's iCloud Drive through your Fire tablet's browser and to inspect files kept on your tablet.

1. Start Cloud Files

  1. Open Cloud Files on your Fire HD 8.
  2. The Home screen shows iCloud Drive actions for Upload and Download, plus Browse Local Files.
  3. Tap About at the bottom for the app version and privacy information.

2. Upload a Fire file to iCloud

  1. On Home, tap Upload.
  2. Tap Open iCloud Drive. On the Android app, Apple's site opens in your Fire's browser, not inside Cloud Files.
  3. Sign in to your Apple Account on Apple's own website if asked.
  4. Open the destination folder and use Apple's Upload control.
  5. Choose Choose Files, then select a file from your Fire tablet.
  6. After Apple confirms completion, return to Cloud Files using the app switcher.
Important: Cloud Files does not receive your Apple password or upload your file itself. Apple's iCloud site handles the transfer.

3. Download a file from iCloud

  1. On Home, tap Download, then Open iCloud Drive.
  2. In your Fire browser, find the file on Apple's iCloud website.
  3. Select the file and use Apple's Download control.
  4. To find it afterward, look in the browser's Downloads area or the tablet's Downloads / Files area.
The file destination and download confirmation are controlled by Apple and the Fire browser, not by Cloud Files.

4. Browse local files

  1. Return to Cloud Files Home and tap Browse Local Files.
  2. Tap Browse Local Files again to open the tablet's file picker.
  3. Open Downloads or another location and select a file.
  4. Cloud Files displays its name, type and size. Use Grid or List to change the display.

Cloud Files is a file-access helper, not a general-purpose file manager. It does not keep a Recent Files history.

5. Appearance and privacy

  1. Tap the Auto / Day / Night button to select an appearance.
  2. Auto follows the time of day; if permitted, the app may use your location on the device to estimate sunrise and sunset.
  3. Cloud Files does not operate your iCloud account or store downloaded file content.

6. If something does not work

iCloud does not open

Check your Internet connection and make sure the Fire tablet has an available browser. Reopen Cloud Files and try again.

You cannot find a downloaded file

Check the Silk browser Downloads screen and the tablet's Files / Downloads folder. Apple and Fire OS decide where the download goes.

A file does not appear under Local Files

Tap Browse Local Files and select it through the system picker. Cloud Files does not list all stored files automatically.
