Another Text Editor (ATE)
Quick Start Guide

A clear space for writing and editing code.

Updated 12 November 2026 · All platforms: 0.6.0 (19).

Download this guide as PDF

Availability: iPhone/iPad and universal Mac are in invitation-only TestFlight. Android APK, Windows x64 installer and the signed, notarized universal Mac installer are on Cuberoot.

1. Get ATE

ATE means Another Text Editor. It is a simple full-screen text and code editor. No account or sign-in is required.

  • Android: download the signed APK from the ATE page on Cuberoot. Open the downloaded file and follow Android’s installation prompts. If asked, allow your browser or Files app to install this file; you can turn that permission off afterwards.
  • iPhone/iPad: ATE is in TestFlight. Accept your invitation, open TestFlight and tap Install or Update. It is not yet an App Store release.
  • Windows: download the Windows x64 installer from Cuberoot, open it and follow the setup prompts. It installs for your Windows account. The Windows installer is unsigned, so Windows may show an unknown-publisher warning.
  • Mac: native Mac TestFlight is available for Intel and Apple silicon. Accept the invitation in TestFlight on your Mac. The signed and notarized universal Mac installer is also available from Cuberoot.

2. Write or open a file

  1. Open ATE and tap the large editing area to write.
  2. To open an existing file, tap Menu → Open and choose a plain-text file from your device or an available file provider.
  3. Use Menu → New for a blank document. Confirm replacement only after saving anything you need.

3. Choose readable text

Tap Menu. Use Text size or A− / A+ to set the display from 10 to 54 pt; the default is 27 pt. Choose Light or Dark, and Text or Icons for buttons. These settings change your view, not the contents of your file. Tap Done to return.

Menu, search, syntax messages and C configuration use 12 pt text, with headings no larger than 14 pt. Document text size remains independent.

4. Save your file

  1. In Menu, enter a File name, such as notes.txt or script.py. Choose Done.
  2. Choose Save file. On iPhone/iPad, choose Save to Files in the share sheet. On Android/Fire, the system file manager opens. Choose a folder, enter the filename and tap Save.
  3. Windows/Mac desktop: the native Save dialog opens. Choose a folder and filename, then Save. Selecting an existing file can replace it after the system confirms.

iPhone/iPad shares a copy. Android and desktop Save write to the chosen destination. Cancelling or failing a save keeps your text and recovery draft; Save and close/exit waits for a successful write on Android and desktop.

Keep independent file copies. A local recovery draft is not a backup or cloud synchronization.

5. Find, replace and copy

Menu → Search / Replace opens Find and Replace fields. Use Next or Previous to move between matches. Replace changes one match; Replace all changes the document. Undo mistakes with Ctrl+Z or Command+Z.

For copying the whole document, choose Menu → Select all, reopen Menu and choose Copy. Paste in your other app. Copy does not remove text.

6. Close your document

Tap Close, then choose Keep editing, Save and close, or Close without saving. Closing without saving removes the recovery draft and clears the editor; files already saved on the device remain.

iPhone/iPad: no extra “Editor closed” page appears. Use the Home gesture to leave the app. Android: Close also leaves the app; Android Back closes an open panel first, or opens the closing choices.

Windows/Mac desktop: choose Exit for Keep editing, Save and exit, or Exit without saving. The window close button and Mac Quit also open these choices. A confirmed exit closes the application.

7. Try Vim only if you want it

With a hardware keyboard, choose Menu → Editing → Vim. Press i to type and Esc or Ctrl+[ for Normal mode. Type /word, press Enter, then n for the next match or N for the opposite direction. Type : in Normal mode for a command. Return to Standard for ordinary editing.

8. Check C without installing a compiler

Choose C as the language, then Menu → Check syntax. The included offline parser checks basic structure without downloads. Headers, macros and types are not checked. On Mac/Windows, optional Clang checking is under Menu → C settings → C checking → Advanced: installed Clang. Switch back to Basic offline parser whenever you prefer.

Other offline checks: JavaScript, TypeScript syntax, JSON, HTML, CSS, YAML, Python syntax and SQLite SQL are included. Markdown reports selected lint warnings. No source is executed and no Python interpreter or database installation is needed.

ATE detects languages from filenames and a local text scan. You can override Language in Menu. Save preserves extensionless names; it does not append .txt.
