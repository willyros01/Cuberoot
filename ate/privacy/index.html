ATE Privacy Policy

Updated 16 November 2026

Another Text Editor (ATE) is provided by Wilfredo Rosales. This policy covers iPhone, iPad, Mac, Windows, Android and the web editor.

Your documents stay local

ATE has no account, advertising, analytics SDK or developer-operated document server. It does not send document contents, filenames, project files, clipboard contents or syntax-check results to the developer. Editing, language detection and bundled syntax checks run locally. Code is not executed.

Storage and recovery

ATE stores recovery tabs, display preferences, project selection and the accepted terms version on your device. Recovery has limited capacity and is not a backup or cross-device synchronization. iPhone/iPad projects are in ATE's Documents storage. Mac/Windows and Android projects use the app's private storage. Web projects use that browser's IndexedDB. Files saved or shared to a destination you select are managed by that destination and its provider.

Your choices and deletion

Close or discard tabs to remove their recovery copies. Removing a file from project membership keeps its stored copy; Delete folder removes the confirmed subtree. Save needed copies before clearing browser/site storage or uninstalling. These actions can remove private projects and recovery. Saved external files may remain and can be deleted using Files or your file manager. There is no ATE online account to delete.

External destinations

Opening help, privacy or support pages sends an ordinary web request to Cuberoot's hosting providers (GitHub Pages and Cloudflare), which can process IP addresses and standard request information. Cuberoot's download pages separately count download clicks, including platform/build, timestamp and browser timezone for approximate regional reporting; that is website activity, not editor document telemetry. ATE does not request GPS location, contacts, camera, microphone or photos. Selecting Files, sharing, cloud providers or sending a support email is your choice and is subject to those services' privacy policies.

Optional desktop compiler

The Mac App Store version uses bundled offline C checking and does not offer external Clang. The website Mac/Windows versions can use an installed compiler only when selected. Optional Windows compiler setup downloads a verified upstream LLVM-MinGW archive; the download host receives a normal network request. Document text is checked locally and is not uploaded to that host.

Apple diagnostics and support

Apple may collect store, TestFlight or system diagnostics under your Apple settings and policies. If you email Support, we receive the information you choose to send and use it to answer your request. Please do not send confidential source files, passwords or keys.
