Help for Another Text Editor on iPhone, iPad and Mac, plus Android, Windows and the web.

Learn ATE

Quick Start covers writing, tabs, saving and Projects. The Full User Guide explains all supported syntax checks, Vim, project transfer and recovery.

Cannot find a saved file?

On iPhone/iPad, complete Save to Files in the share sheet and check the chosen folder. Closing the share sheet alone does not confirm a save. Android and Mac/Windows use a native file dialog. A recovery draft is not a saved file or backup.

Cannot type or find a project?

In Vim, press i or switch Editing to Standard in Menu. Projects is under Advanced mode. Use Open project to choose a saved project or create one; select a folder before Add file or New folder. Tap a file in the tree to open its tab. Close project keeps saved project files.

Syntax checking

Use Advanced mode and Check syntax. SQL supports SQLite syntax. Python checks syntax without running code. Basic C does not check headers, macros or types. The Mac App Store version uses the bundled C parser; an external compiler is not required.
