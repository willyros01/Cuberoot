Readable by design

  • 27 pt editor text by default, adjustable from 10 to 54 pt.
  • Switchable text or icon buttons and light/dark themes.
  • Search, replace, go to line, select all and copy.
  • Optional Vim: Normal/Insert modes, searches and common colon commands.
  • Local recovery draft; save independent file copies through the system share sheet.

ATE works without an account and does not run your code. Recovery drafts stay on this device; they are not cloud backups. Save copies before clearing app data or uninstalling.
