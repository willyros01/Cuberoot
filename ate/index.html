Readable by design

  • 27 pt editor text by default, adjustable from 10 to 54 pt.
  • Readable menu controls and larger project headings and file labels. Switchable text or icon buttons and light/dark themes.
  • Search, replace, go to line, select all and copy.
  • Preview: see an HTML page or Markdown file as it will look, then go back to editing. Read-only and offline: scripts never run and nothing is loaded from the internet.
  • Optional Vim: Normal/Insert modes, searches and common colon commands.
  • Local recovery draft; save independent file copies through the Android file manager, iOS share sheet or desktop Save dialog (Mac, Windows and Linux).

ATE works without an account and does not run your code. Recovery drafts stay on this device; they are not cloud backups. Save copies before clearing app data or uninstalling.

Local code checks

ATE includes offline JavaScript, TypeScript syntax, JSON, HTML, CSS, YAML, Basic C, Python syntax, sh/Bash, SQLite SQL, Java 21 syntax, XML, TOML and INI checks, plus selected Markdown lint warnings. C++, C#, Go, Rust, PHP, Ruby, Swift, Kotlin, PowerShell and Lua have keyword colors only. Files keep their names, including names without an extension. Code is not executed during checking.
