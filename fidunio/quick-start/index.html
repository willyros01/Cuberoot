1. Get set up

  1. Install FIDUNIO from the App Store on iPhone/iPad, or the Cuberoot signed Android download. The web app is also available.
  2. Open your personal invitation. Enter your profile name, email, password and six-digit PIN. Existing members use Sign In.
  3. In Settings choose A, A+ or A++ text and Auto, Light or Dark appearance. Enable notifications on this device.
  4. Create a Recovery File in Settings > Data and save it outside the app. Keep your password and PIN private.

Check Settings > About. This guide describes 1.1.88; the App Store and testing channels may differ.

2. Send an everyday message

  1. Open Messages and select a chat, or use + to start a direct conversation or group.
  2. Type your message and tap Send. Queued/Sending is still waiting; Sent confirms server acceptance.
  3. Use the attachment control for photos, videos, audio or files. Press and hold a message for Copy, Select Text, reactions or eligible Reply/delete actions.
  4. Tappable web links ask Open this link? before leaving the app. Read deletion confirmations carefully.

The full guide covers groups, disappearing messages, recovery, administration and troubleshooting.

3. Choose contacts and send HELP

  1. Settings > Safety > HELP > Choose HELP contacts. Select up to five trusted FIDUNIO members, then Save.
  2. Ask those people to open FIDUNIO and turn on notifications. Resolve any contact can't hear HELP yet warning.
  3. On Messages, tap HELP. Hold the large button for two seconds until the ring completes.
  4. Allow location if wanted. Check for HELP is sent; type extra information on the same screen. If HELP did not go out, check the connection and hold again.

HELP alerts your contacts; it does not call emergency services. Location is a point, not continuous tracking. Delivery and sound depend on connectivity and device settings.

4. Respond and close HELP

  1. A helper taps the notification and unlocks if asked. The red screen shows who needs HELP.
  2. Use Open in Maps when location arrives. Tap I'm coming when you can respond, then exchange messages on the same screen.
  3. The sender sees the responding contact's name on a green screen. When safe, the sender taps I'm OK now to close the alert.
  4. The HELP conversation is also the ordinary chat. After closure, ordinary message notifications open that chat.

If notifications are off, use Turn on or Open Settings. Apple Critical Alerts approval is pending; HELP is not guaranteed to bypass silent mode or Focus. Read the illustrated HELP Guide for all steps.
