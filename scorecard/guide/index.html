The Scorecard User Guide

Quick start for the iPhone app and the web app.

Download the PDF guide

Start or join

A group owner creates the group and sends invitation links. A golfer normally joins by opening their named invitation. Use the same invitation only for the person named in it.

Use the iPhone app

  1. Install The Scorecard from TestFlight or the App Store.
  2. Open an invitation link. If the app is installed, the iPhone opens it directly; otherwise the web app opens.
  3. When asked, sign in with the same email and password you use on the web.
  4. Choose your group and confirm your golfer name and recent rounds.

Use the web app

Open willyros01.github.io/scorecard. You may continue using the web app after the iPhone app is available. Both use the same Firebase account and shared group data.

Moving from the web app to the iPhone app

Your golfer, rounds and handicap are not on your phone — they are in the group. Moving only means signing in to the same account in the iPhone app. Never create a second golfer.

Before you move — in the web app you normally use

  1. Be online. Tap the status button at the top right. It must say Synced. If it says Saved on device with rounds waiting, keep the web app open and online until it says Synced. If it never does, do not move — tell the group owner.
  2. Back up: status button → Back up my data → Save it somewhere → Save to Files.
  3. Keep the web app. Do not delete its home-screen icon or clear Safari until the checks at the end pass.

Then, depending on who you are

  • Owner, or admin with a password: in the iPhone app, tap Sign in on the first screen and use the same email and Scorecard password.
  • Admin without a password: first, in the web app, tap the status button → Set a password. Then sign in on the iPhone as above.
  • Guest without a password: in the web app, tap the status button → Set a password, using an email that has no Scorecard account yet. The message must say Password saved. Then sign in on the iPhone with that email.
  • If the message said "Signed in to your existing account" instead, or you would rather not set a password: ask the group owner to tap Let them join again on your name and send you a new invitation from the iPhone app. Open that invitation on your iPhone.

After moving — check before removing the web app

  • The group name and roster appear.
  • History shows the same rounds as the web app.
  • Your handicap matches the web app.

Only then is the web app optional. Owners and admins can keep using both — it is the same account.

Enter and correct a round

  1. Open the group and choose the entry screen.
  2. Select the golfer, course and tee; enter the adjusted score.
  3. Post the round. If offline, leave the app installed and reconnect later so the queued round can upload.
  4. A golfer can correct their own round during the 24-hour window. Group administrators can make later corrections.

Handicap and group history

The Scorecard calculates handicap from stored rounds using the World Handicap System method used by the app. A golfer may play in several groups while keeping one golfer record and one handicap history.

Account deletion

At the bottom of any screen, tap Delete my account. A group owner must first delete the groups they own; ownership cannot be transferred. Your account connection is removed, but your golfer name, rounds and handicap history stay in the shared golf record.
